## Introduction

Cross-View Supervision introduces a training-only supervision strategy for online HD map construction. A frozen aerial-image teacher provides structural BEV feature supervision to an ego-centric onboard-view student. During inference, the student operates using onboard sensors only and does not require aerial imagery.
